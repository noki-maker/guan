# 易路 · 六十四卦背诵

一款帮助背诵《易经》六十四卦的纯前端小应用，无需安装、无需联网，手机或电脑打开 `index.html` 即可使用。

## 功能介绍

### 学习

由浅入深的学习路线：**阴阳 → 四象 → 八卦 → 六十四卦 → 背诵方法**。每个阶段配有图文讲解，帮助理解爻、卦画与八宫推演规律，告别死记硬背。首页实时显示背诵进度。

![学习页](img/show.png)

### 卦象

六十四卦全览，可按**卦序**或**八宫**筛选浏览。点击任意卦进入详情：

- 卦画、卦名、拼音、上下卦与五行
- 卦辞及注释、《大象》及注释
- 自下而上六爻爻辞及注释

生僻字、多音字均带拼音标注，学完一卦可点「已掌握」打卡。

### 自测

每轮 10 题四选一，两种题型双管齐下：

- **看卦画认卦名**：由象及名
- **看卦名认卦画**：由名及象

自动记录最佳成绩，检验记忆效果。

## 适用人群

- 零基础、希望从阴阳八卦学起的入门者
